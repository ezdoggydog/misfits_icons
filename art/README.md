# Celestial Misfits art

Banners, logos and item art (October 2026). Link any file with
`https://raw.githubusercontent.com/ezdoggydog/misfits_icons/main/art/<folder>/<file>`

## banners/  (one set per season)
`<season>_wide.jpg` full size · `<season>_1024x512.jpg` · `<season>_512x256.jpg` (Rust server browser header, `server.headerimage`)

Seasons: regular, newyear, valentines, easter, memorial, july4, laborday, pirate,
halloween, muertos, usmc (Marine Corps Birthday), veterans, thanksgiving, christmas.

## logos/
- `hound_square_*` main logo (cigar hound on the moon, full sky; `server.logoimage`, Discord)
- `hound_round_*` the same, round with a transparent edge
- `hound_sticker_*` cigar hound, sticker style
- `howling_dog_*` howling dog version
- `rocket_badge_*` round riveted badge with the rocket
- `rocket_moon_poster.jpg`, `rocket_moon_icon_*` rocket-and-moon poster and its square icon

### Title badges (`title_<name>_<size>.png`)
Art for the titles players collect (see the roadmap's "Title collecting + the Title King").
Transparent, square, 1024 / 512 / 128.
- `title_cattlepult_test_pilot_*` a cartoon cow flying sideways, "CATTLEPULT — TEST PILOT".
  For the secret title earned by **surviving a CattlePult cow** (RocketMan launches live cows
  that go off like C4 on impact). Made with Grok, added Nov 10, 2026.

## items/
Insurance policy and vehicle keys (sedan, pickup, minicopter, boat, utility truck), transparent 512 px.
